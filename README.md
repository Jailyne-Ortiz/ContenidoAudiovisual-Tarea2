# Proyecto “Contenido Audiovisual”

## Descripción del proyecto:

Este proyecto ayuda a la profundización y mejor entendimiento de la Programación Orientada a Objetos, adentrándose en términos como la herencia, asociación, agregación y composición; así como también el manejo y el conocimiento de herramientas para trabajar juntamente con otros programadores.

Dentro de este proyecto se podrá visualizar a detalle distintos tipos de contenido audiovisual con sus atribuciones únicas.

---

## Propósito de la aplicación y qué problema resuelve:

El presente proyecto permite una revisión rápida de los diferentes tipos de contenido audiovisual que comparte características en común, así como también encontrar diferencias significativas que pueden influir en la decisión del público en general sobre ver o no cierto tipo de filmes.

Por otro lado, el proyecto permite evitar la duplicación de código al importar proyectos desde herramientas comunes como GitHub, así como también, subir nuevos proyectos con modificaciones y extender estos códigos a más personas para que puedan seguir mejorándolos.

---

## Características principales:

- Uso de herencia mediante la clase padre “ContenidoAudiovisual”
- Aplicación de polimorfismo con el método “mostrarDetalles()”
- Asociación entre clases como actor, temporada e investigador
- Organización en distintos paquetes como uni1a y poo

---

## ¿Cómo clonar el repositorio?

1. Copiar el URL del repositorio:  
   https://github.com/Jailyne-Ortiz/ContenidoAudiovisual-Tarea2.git

2. Abrir Eclipse, buscar File en la parte superior, clic derecho y buscar Import

3. Dar click en la carpeta Git y seleccionar Projects from Git, dar clic en next

4. Seleccionar Clone URI, presionar next y en la sección de Location pegar el URL antes proporcionado

5. En el apartado de Authentication ingresar el usuario y la contraseña de GitHub y dar clic en next

6. Selecciona todo lo que desees descargar y elige en qué carpeta guardarlo, finalmente se importará el proyecto
